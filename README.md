# 🧮 Simple GUI Calculator using Java
## ⭐ Project Overview
This is a basic calculator application developed using the Java programming language. It provides a user-friendly Graphical User Interface (GUI) for performing standard arithmetic operations (addition, subtraction, multiplication, and division). The project focuses on creating an efficient and visually appealing desktop tool leveraging Java's foundational GUI libraries.
## 🛠️ Technologies Used
* Java -> Core programming language.
* AWT (Abstract Window Toolkit) -> Used for basic window components and event handling.
* Swing -> Used for creating more advanced, look-and-feel independent GUI components, making the application more attractive.
## ✨ Features
* Standard Operations: Supports addition (+), subtraction (-), multiplication (*), and division (/).
* Decimal Support: Handles floating-point numbers.
* Clear Functionality: A clear button (C) to reset the input and result.Intuitive
* GUI: A clean and easy-to-use interface built with Java Swing components
